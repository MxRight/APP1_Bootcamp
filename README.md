# APP1_Bootcamp

## Описание проекта

**APP1_Bootcamp** — это учебный проект, направленный на освоение практических основ программирования на языке **Python**.  
В ходе выполнения проекта участник постепенно знакомится с основными возможностями языка, принципами **объектно-ориентированного программирования**, а также проходит путь от простых задач к созданию полноценного консольного приложения.

Финальным результатом является разработка небольшой **rogue-like игры**, где основной упор сделан на логику, архитектуру и взаимодействие объектов, а не на графику.  
Проект помогает закрепить ключевые концепции — от написания функций и классов до организации кода, обработки пользовательского ввода и проектирования игрового цикла.  

### Цели проекта

- Освоить базовые конструкции и синтаксис Python.  
- Научиться применять принципы ООП для моделирования объектов и их взаимодействия.  
- Познакомиться с процессом пошаговой разработки консольного приложения.  
- Получить опыт структурирования проекта и написания читаемого, поддерживаемого кода.

### Основные темы

- Функции, модули, работа с файлами  
- Классы, наследование, инкапсуляция и полиморфизм  
- Исключения и обработка ошибок  
- Игровая логика и управление состоянием программы  
- Работа с текстовым интерфейсом  

### Итог

Проект сочетает теорию и практику: от простых упражнений до создания мини-игры с элементами случайности, картой уровней и взаимодействием между персонажем и окружением.  
Он служит отличной тренировкой для тех, кто хочет научиться писать живой, функциональный код и лучше понимать философию Python.
