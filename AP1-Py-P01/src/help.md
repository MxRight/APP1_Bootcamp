# Rogue remake help:

## Управление

Управление производится с клавиатуры, используются следующие клавиши:

- `w` - вверх
- `s` - вниз
- `a` - влево
- `d` - вправо
- `h` - применение оружия из рюкзака 
- `j` - применение еды из рюкзака
- `k` - применение эликсира из рюкзака
- `e` - применение свитка из рюкзака


## Значение символов

### Главный герой:
- `@` - главный герой
### Монстры:
- `z` - зомби 
- `v` - вампир
- `g` - привидение
- `O` - огр
- `s` - змей-маг
- `m` - мимик

### Предметы: 
- `$` - сокровище, золото
- `%` - еда
- `!` - эликсир/зелье
- `*` - свиток
- `)` - оружие
- `~` - ключ

### Интерьер:
- стена
- пол
- проем в стене
- дверь
